# cs-230-Portfolio
CS-230 Operating Platforms Portfolio

Client and Software Requirements 

The Gaming Room was a client looking to expand their existing game, Draw It or Lose It, into a web-based application that could run on multiple platforms. The client wanted a system that could support multiple teams and players while ensuring that each game, team, and player had a unique name. The software also needed to be secure, efficient, and accessible across different operating systems. My responsibility was to help design a solution that would meet these requirements while considering performance, security, and scalability. 

Strengths in Developing the Documentation 

One area I did particularly well in was organizing the software design document and explaining the technical requirements clearly. I was able to compare different operating platforms and identify their advantages and disadvantages for The Gaming Room application. I also explained important considerations such as memory management, security, and system architecture. This helped me better understand how different technical decisions can affect the overall performance and reliability of an application. 

How the Design Document Helped with Coding 

Working through the software design document helped me understand the importance of planning before writing code. By identifying the client's requirements, system architecture, and technical limitations ahead of time, I was able to better understand how the application should function. The design document also helped me organize my ideas and recognize potential problems before development. This process made it easier to understand how different parts of the program connect and work together. 

Areas for Improvement 

If I could revise one part of my software design document, I would improve the section comparing different operating platforms. I would include more detailed examples explaining how each platform affects performance, security, and compatibility. I would also provide clearer explanations for why certain platforms would be better suited for The Gaming Room application. These improvements would make the document easier to understand and help support the technical decisions made during the design process. 

Understanding and Implementing User Needs 

I interpreted the user's needs by reviewing the requirements provided by The Gaming Room and identifying the features necessary for the application. These included supporting multiple players and teams, allowing access across different platforms, and ensuring that each game had a unique name. I considered these requirements when planning the software architecture and recommending an appropriate operating platform. Understanding the user's needs is important because it helps developers create software that is functional, reliable, and meets the client's expectations. Without considering these needs, the final product might not solve the problems it was designed for. 

Software Design Approach and Future Strategies 

My approach to designing software involved understanding the client's requirements, planning the system architecture, and evaluating different technical solutions. I focused on how the application would function across multiple platforms while considering factors such as security, performance, and scalability. In future projects, I would continue using software design documents to organize my ideas before beginning development. I would also use diagrams, research different technologies, and gather feedback throughout the design process. These strategies would help me make better decisions, identify potential problems early, and develop more reliable software applications.
